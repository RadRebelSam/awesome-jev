Privacy

Awesome Jev is a directory of open-source projects. It has no accounts, no logins and no adverts.

Last updated 20 September 2026.

What is collected

WhatWhenWhy
Page views, referring site, approximate country, browser and device type, and which outbound links are clicked Every visit To see whether anyone is reading the directory and which listed projects people actually open
Your email address Only if you type it into the newsletter box and submit it To send the weekly digest, and nothing else

What is not collected

  • No cookies are set by this site, which is why you are not being asked to consent to any.
  • No session recording, no mouse tracking, no fingerprinting, no advertising or cross-site tracking.
  • No names, no addresses, no payment details. There is nothing to pay for.
  • Your full IP address is not stored. It is used in transit to derive an approximate country, then discarded.

Who processes it

  • Analytics — Rybbit, a cookieless analytics service, on this site's behalf.
  • Newsletter — rasa.io stores subscriber addresses and sends the digest.
  • Hosting — GitHub Pages. GitHub keeps its own server logs of requests, under GitHub's privacy statement, which this site does not control.

Nothing is sold, rented, or shared with anyone else, and the data is not used to train anything.

How long it is kept

Analytics are aggregate and retained by the analytics provider under its own retention period. Your email address is kept until you unsubscribe, after which it is deleted.

Getting it removed

Every digest has an unsubscribe link, and one click ends it. If you would rather ask directly, or you want anything else deleted, open an issue or message me on GitHub and I will do it. You do not need to give a reason.

If you would prefer not to be counted in the analytics at all, any tracker blocker stops it, and so does your browser's Do Not Track setting.

Changes

If what is collected ever changes, this page changes with it and the date above is updated. The page is version-controlled in the repository, so every edit is public history.
